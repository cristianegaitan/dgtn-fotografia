# DGTN — Fotógrafo y Filmmaker

Sitio web profesional de Damián Gaitán, fotógrafo y filmmaker en Córdoba y Río Cuarto, Argentina.

## Sitio publicado

[Ver sitio web](https://cristianegaitan.github.io/dgtn-fotografia/)

## Descripción

El sitio presenta su trabajo, servicios y medios de contacto mediante una interfaz oscura, visual y adaptable a diferentes tamaños de pantalla.

## Características

- Diseño responsive para computadoras y dispositivos móviles.
- Secciones de portfolio, servicios, presentación y contacto.
- Navegación interna entre secciones.
- Enlaces directos a WhatsApp e Instagram.
- Publicación mediante GitHub Pages.

## Tecnologías

- HTML5
- CSS3
- Git y GitHub
- GitHub Pages

## Estado del proyecto

En desarrollo. La próxima etapa será incorporar fotografías originales al portfolio.
