# DGTN — Fotógrafo y Filmmaker

Sitio web profesional de Damián Gaitán, fotógrafo y filmmaker en Córdoba y Río Cuarto, Argentina.

## Sitio publicado

[Ver sitio web](https://cristianegaitan.github.io/dgtn-fotografia/)

## Descripción

Portfolio diseñado para presentar trabajos fotográficos y audiovisuales, servicios profesionales y medios de contacto.

El sitio utiliza una estética oscura centrada en las imágenes y está adaptado para computadoras, tablets y teléfonos.

## Características

* Diseño responsive.
* Menú de navegación para dispositivos móviles.
* Galería de trabajos con visor de imágenes.
* Navegación mediante teclado y mejoras de accesibilidad.
* Enlaces directos a WhatsApp e Instagram.
* Metadatos para buscadores y redes sociales.
* Vista previa al compartir el sitio.
* Favicon personalizado.
* Imágenes optimizadas para mejorar la velocidad de carga.
* Publicación mediante GitHub Pages.

## Optimización de imágenes

Las fotografías originales se guardan en la carpeta `images-originales`, que está excluida del repositorio.

Para instalar las dependencias:

```bash
npm install
```

Para generar las imágenes optimizadas:

```bash
npm run optimizar
```

Las imágenes procesadas se guardan en la carpeta `images`.
